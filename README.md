# ГАЗЯВА — Dew Bass Saturator (VST3 для FL Studio)

## Обновить плагин на GitHub
1. В репозитории: **Add file → Upload files**.
2. Перетащи `CMakeLists.txt`, папки `Source` и `Assets` (одноимённые файлы перезапишутся).
3. **Commit changes** → вкладка **Actions** → дождись зелёной галочки → скачай `Gazyava-Windows`.
4. Закрой FL Studio, замени папку `Gazyava.vst3` в `C:\Program Files\Common Files\VST3\`, запусти FL → Find installed plugins.

## Режимы бас-бустера (клик по банке)
ЛАЙМ — ламповый буст · ТРОПИК — мягкая лента · ГРОМ — тяжёлый фазз · СИНИЙ — чистый буст + саб-октава · ЧЁРНЫЙ — жёсткий клип

## Мяуканье манулов
Клик по коту — мяу. Звуки лежат в `Assets/meow1.wav` (левый) и `Assets/meow2.wav` (правый).
Сейчас там синтезированные заглушки. Чтобы поставить настоящие: скачай CC0-мявы (OpenGameArt: "Cat Purr & Meow" автора Kerzoven, "Meow" автора IgnasD),
переведи в WAV (ogg → wav, например в Audacity), назови `meow1.wav` / `meow2.wav`, загрузи в `Assets/` и закоммить.
Если мяу не слышно в FL: в окне обёртки плагина (шестерёнка) выключи **Smart disable**, и убедись, что играет трек/транспорт.

## Свои картинки
Все спрайты в `Assets/`. Замени файл на свой с ТЕМ ЖЕ именем и закоммить.
